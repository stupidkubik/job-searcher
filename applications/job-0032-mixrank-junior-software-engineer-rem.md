## Суть роли

Это не backend-only вакансия, а открытая generalist junior role. MixRank нанимает инженеров под разные области продукта и прямо пишет, что обязанности могут быть настроены под интересы кандидата: web applications, frontend/backend web development, APIs, databases, data mining, ML/data science, infrastructure and tooling.

Основной технологический контекст компании: Python, Rust, SQL, JavaScript/TypeScript и Nix. Для быстрой продуктивности MixRank отдельно выделяет Python, PostgreSQL, Linux и Git.

- Python, PostgreSQL и Linux названы core technologies for productivity, а в подтверждённом основном профиле они не являются сильной стороной.
- Роль generalist и значительная часть инженерных задач MixRank находится в data/infrastructure/backend зоне; frontend-направление не гарантируется заранее.
- Компания подчёркивает многолетнюю самостоятельную техническую любознательность и hobby programming. Не стоит заявлять конкретные «5+ лет», если это нельзя подтвердить.
